## ✨ Features

- **Blazing Fast Performance**: Built with Vite and pure CSS Modules for an incredibly lightweight bundle and instant load times.
- **Deep Dark Mode Aesthetics**: A modern, custom-designed dark theme with electric blue and purple accent gradients.
- **Fluid Micro-Animations**: Smooth scroll reveals, staggered layout entrances, and interactive hover states powered by `framer-motion`.
- **Fully Responsive**: Flawless layout adaptation across desktop, tablet, and mobile viewports using CSS Grid and Flexbox.
- **Modular Component Architecture**: Clean, maintainable React codebase following senior-level best practices.

## 🛠️ Technologies Used

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Modules & Custom Variables)
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 💻 Local Setup

Want to run this project locally? Follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/poojasingh1231/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
